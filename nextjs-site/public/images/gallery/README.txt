===================================================================
ADHIKARI GROUP - SCROLLING PICTURE GALLERY FOLDER (images/gallery/)
===================================================================

This folder is dedicated exclusively to the bottom scrolling picture gallery.

HOW TO ADD NEW IMAGES:
1. Drop your image files (e.g. photo1.jpg, store.png, event.webp) directly into this folder:
   images/gallery/your-image-name.jpg

2. Open "js/data.js" and add your image into the "galleryImages" list:
   { id: "img-6", src: "images/gallery/your-image-name.jpg", alt: "Description" },

That's it! The picture will automatically appear in the bottom scrolling gallery.
